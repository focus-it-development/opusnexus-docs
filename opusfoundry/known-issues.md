# OpusFoundry known issues

These are the current Beta limits. Most are on the plan.

1. Artwork must be SVG. Reading Illustrator (.ai), EPS and PDF directly is planned. For now, save a copy as SVG.
2. Tracing from PNG or JPG pictures, and accented letters, are not in this beta.
3. The Mac build is unsigned and has not been tested on a real Mac yet. See [Getting started](getting-started.md) for the one-time steps to open it.
4. Beta installers are not code signed, so Windows shows a SmartScreen warning the first time.
5. Some Final check flags have no automatic fix, such as a stem that is bolder than the rest. Those offer Accept current state, with a hint to fix it in the artwork.

Found something not listed here? Open an issue in this repository or email beta@opusnex.us.
