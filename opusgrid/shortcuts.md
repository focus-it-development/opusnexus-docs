# OpusGrid keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Select, Text, Box, Ellipse, Diamond | V, T, R, E, D |
| Connector, Wall, Room | C, W, M |
| While drawing walls | Type a length, Enter to place, Enter again to finish, Esc to stop |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Copy, paste, duplicate | Ctrl+C, Ctrl+V, Ctrl+D |
| Select all | Ctrl+A |
| Group, ungroup | Ctrl+G, Ctrl+Shift+G |
| Rotate 90° | Ctrl+R |
| Edit the selected shape's label | Enter |
| Nudge (fine nudge) | Arrow keys (Shift+Arrow) |
| Delete | Delete |
| Copy the page as an image | Ctrl+Shift+C |
| Zoom in, zoom out, fit the page | Ctrl+Plus, Ctrl+Minus, Ctrl+0 |
| Pan | Space and drag, the middle mouse button, or the scroll wheel |
| New diagram, open | Ctrl+N, Ctrl+O |
