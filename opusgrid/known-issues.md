# OpusGrid known issues

These are the current Beta limits. Most are on the plan.

1. Windows x64 only for now. A Mac version is planned.
2. Rotation is in 90° steps.
3. Rack and cabling diagrams do not generate a logical network map. Network topology stays on its own templates.
4. Rack to rack cables get no suggested length. Cable length inside a single rack is suggested, and you accept or change it.
5. Parallel cables are spread apart, but there is no smart bundling or crossing avoidance yet.
6. Device faceplates use one generic OpusGrid style. Vendor-specific artwork is not included.
7. PNG and PDF exports may show diagram text in Segoe UI rather than Roboto.
8. Beta installers are not code signed, so Windows shows a SmartScreen warning the first time. See [Getting started](getting-started.md).

Found something not listed here? Open an issue in this repository or email beta@opusnex.us.
