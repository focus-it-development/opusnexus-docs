# Getting started with OpusType

## Install

1. Download the installer from your beta invitation and run it. It installs for your account only, so no admin rights are needed.
2. Beta builds are not code signed yet, so Windows may show "Windows protected your PC." Click **More info**, then **Run anyway**.

The first time OpusType opens, a short four-card tour shows the basics. You can replay it any time with **Take the tour** next to the version number on the start screen.

## Your first document

1. Click **New document** (or press Ctrl+N).
2. Give it a name and pick Rich text, Plain text, or Code.
3. Start typing. There is no Save button to remember.

## Where your documents live

OpusType saves everything to `Documents\OpusType`, about 1.5 seconds after you stop typing. The status in the top right shows Edited, Saving, or Saved. If OneDrive backs up your Documents folder, OpusType saves there and shows a cloud icon.

Files you open from somewhere else save back to where they came from.

## Rich, Plain, or Code

The switch in the top bar sets what kind of document you are working on.

| Type | Saves as | Good for |
| --- | --- | --- |
| Rich | `.rtf` | Letters, notes, anything with headings, lists, and bold text. Opens in Word and LibreOffice. |
| Plain | `.txt` | Notes and text with no formatting, shown edge to edge like Notepad. |
| Code | The language's own extension | Scripts and config files, with syntax colors and line numbers. |

Leaving Rich asks first, since formatting is removed. Plain and Code switch back and forth with nothing lost.

## Formatting in rich text

The toolbar has bold, italic, underline, strikethrough, three heading sizes, bulleted and numbered lists, and alignment. The Font and Size boxes use any font installed on your PC. Roboto at 12 pt is the default.

Shortcuts while typing: `- ` or `1. ` at the start of a line starts a list, and `# ` starts a heading.

## Pasting

Pasted text drops fonts, colors, and sizes but keeps line breaks, tabs, and spaces, so it always matches your document.

## Working with code

1. Pick the language in the language box in the top bar. It sets the colors and the file extension.
2. Line numbers are on, matching brackets are highlighted, and new lines keep their indent.
3. Select several lines and press Tab or Shift+Tab to indent or outdent them all.
4. In a JSON file, **Format** (Shift+Alt+F) tidies it. If the JSON is broken, OpusType jumps to the line with the problem.
5. The View button sets word wrap, line numbers, auto-close brackets, the indent, and the display font.

OpusType keeps each file's line endings and encoding as they are. New files get sensible defaults for their language, and you can change both in the View menu.

## Export

Click the export button in the top bar.

1. Rich and Plain export to Word (.docx) and PDF.
2. Code exports to PDF with colors and line numbers, to an HTML page, or copies as colored code for pasting into email, Teams, or Word.
3. Plain and Code can also save a copy as another file type.

## RTF files with images or tables

OpusType cannot keep images or tables in RTF files yet. When a file has them, it offers to **Edit a copy** so the original stays whole.

## Appearance

Click the palette button in the top bar, or **Appearance** on the start screen.

1. **Mode:** System follows your Windows setting. Light and Dark stay put whatever Windows does.
2. **Theme:** each theme is two colors, one for the app bar and one for the body. Pick Slate, Harbor, Forest, Ember, or Plum.
3. **Custom:** choose the app bar and body colors yourself. Text switches between dark and light so it stays readable. **Reset to Slate** goes back to the default.

The document page always stays plain light or dark so your work is easy to read.
