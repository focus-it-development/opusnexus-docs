# OpusType keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| New document | Ctrl+N |
| Open file | Ctrl+O |
| Save now (autosave already handles it) | Ctrl+S |
| Rename document | F2 |
| Bold, italic, underline | Ctrl+B, Ctrl+I, Ctrl+U |
| Strikethrough | Ctrl+Shift+S |
| Heading 1, 2, 3 | Ctrl+Alt+1, Ctrl+Alt+2, Ctrl+Alt+3 |
| Bulleted list, numbered list | Ctrl+Shift+8, Ctrl+Shift+7 |
| Align left, center, right | Ctrl+Shift+L, Ctrl+Shift+E, Ctrl+Shift+R |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Indent, outdent selected lines (Code) | Tab, Shift+Tab |
| Format JSON | Shift+Alt+F |

## Typing shortcuts in rich text

| Type at the start of a line | Result |
| --- | --- |
| `- ` | Bulleted list |
| `1. ` | Numbered list |
| `# ` | Heading |
