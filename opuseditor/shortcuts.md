# OpusEditor keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Select and move, Crop | V, C |
| Arrow, Line, Box, Oval | A, L, R, E |
| Text, Marker, Numbered steps, Pen | T, H, N, P |
| Hide (blur, pixelate, black box) | B |
| Open | Ctrl+O |
| Save project, Save as | Ctrl+S, Ctrl+Shift+S |
| Export a picture | Ctrl+E |
| Undo, redo | Ctrl+Z, Ctrl+Y (or Ctrl+Shift+Z) |
| Copy, paste | Ctrl+C, Ctrl+V (annotations first, then the picture) |
| Copy the finished picture | Ctrl+Shift+C |
| Duplicate the selected annotation | Ctrl+D |
| Select all annotations | Ctrl+A |
| Delete the selected annotation | Delete |
| Nudge (10 pixels) | Arrow keys (Shift+Arrow) |
| Edit the selected text | Enter |
| Finish editing text | Esc or Ctrl+Enter |
| Apply a crop, cancel a crop | Enter, Esc |
| Zoom in, zoom out | Plus, Minus (or Ctrl+Plus, Ctrl+Minus) |
| Fit the picture, actual size | Ctrl+0, Ctrl+1 |
| Pan | Space and drag |
| Zoom with the mouse | Scroll wheel |
