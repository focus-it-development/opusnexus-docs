# OpusLists keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Quick add, from any app | Ctrl+Alt+L (change it in Settings) |
| Go to Today, Scheduled, Lists, All, Done | Ctrl+1, Ctrl+2, Ctrl+3, Ctrl+4, Ctrl+5 |
| Focus the add bar | Ctrl+N |
| Search | Ctrl+F |
| Settings | Ctrl+, |
| Close a menu or dialog | Esc |
