# OpusCanvas known issues

These are the current Beta limits. Most are on the plan.

1. Windows x64 only for now. A Mac version is planned.
2. Capturing uses the Windows snip bar. An OpusCanvas capture bar of its own is planned.
3. Print Screen still opens the Windows snip tool. Making OpusCanvas the Print Screen app is planned.
4. If Snipping Tool's own auto-save is on, OpusCanvas uses the file Windows saved rather than making a second copy.
5. Beta installers are not code signed, so Windows shows a SmartScreen warning the first time. See [Getting started](getting-started.md).

Found something not listed here? Open an issue in this repository or email beta@opusnex.us.
