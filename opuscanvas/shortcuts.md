# OpusCanvas keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| New capture, from anywhere | Ctrl+Shift+S |
| Select and move | V |
| Arrow, Box, Ellipse, Line | A, R, E, L |
| Pen, Highlighter, Text | P, H, T |
| Numbered step, Blur, Crop | N, B, C |
| Delete the selected markup | Delete |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Copy the image | Ctrl+C |
| Fit to window | Ctrl+0 |
