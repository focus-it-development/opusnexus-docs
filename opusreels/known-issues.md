# OpusReels known issues

These are the current Beta limits. Most are on the plan.

1. Windows x64 only for now. A Mac version is planned.
2. Speech recognition is English only.
3. Some files, such as certain HEVC phone recordings, will not play in the preview. OpusReels makes a small temporary preview copy for those. Exports always use your original file.
4. Hardware encoding depends on your graphics card and driver. If one fails, OpusReels tries the next and finally the processor, which is slower. The hardware encoders have had little testing on real PCs so far, so please report export problems.
5. Facecam finding can miss cams with transparent or animated borders, green screen cams and avatar cams. Draw the box by hand in those cases.
6. Free edition exports carry a small watermark and an end card. AI helpers and the Pro license come in a later version.
7. Beta installers are not code signed, so Windows shows a SmartScreen warning the first time. See [Getting started](getting-started.md).

Found something not listed here? Open an issue in this repository or email beta@opusnex.us.
