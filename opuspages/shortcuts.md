# OpusPages keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Open a PDF | Ctrl+O |
| Find | Ctrl+F, then Enter or Shift+Enter |
| Select text | V |
| Highlight, Underline | H, U |
| Pen, Text box, Sticky note, Sign | P, T, N, S |
| Back to selecting | Esc |
| Delete the selected markup | Delete |
| Delete selected pages (thumbnails focused) | Delete |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Zoom in, zoom out, fit to width | Ctrl+=, Ctrl+-, Ctrl+0 |
| Next or previous page | Page Down, Page Up |
| Save as | Ctrl+Shift+S |
| Next or previous answer line in a form | Enter or Down, Up |
| Save now (autosave already handles it) | Ctrl+S |
