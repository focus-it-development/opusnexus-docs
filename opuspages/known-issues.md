# OpusPages known issues

These are the current Beta limits. Most are on the plan.

1. Windows x64 only for now. A Mac version is planned.
2. OpusPages is not yet offered as the default app for PDFs. Open files from the app or drop them on the window.
3. The existing text in a PDF cannot be edited. Add a text box instead.
4. Scanned PDFs cannot be searched, and Find fields cannot read them yet. You can still place fields on a scan by hand.
5. Password protected PDFs open read only.
6. Markup and signatures become part of the page once the PDF is closed. Sticky notes stay real notes.
7. Form fields in inserted or combined PDFs may not stay fillable.
8. Text typed into forms and text boxes supports Latin characters. Other scripts show as question marks for now.
9. Beta installers are not code signed, so Windows shows a SmartScreen warning the first time. See [Getting started](getting-started.md).

Found something not listed here? Open an issue in this repository or email beta@opusnex.us.
