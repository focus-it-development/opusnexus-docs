# OpusTables keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| New table, open file | Ctrl+N, Ctrl+O |
| Edit a cell | F2, double-click, or just start typing |
| Confirm and move down, right | Enter, Tab (add Shift to go back) |
| New line inside a cell | Alt+Enter |
| Cancel an edit | Esc |
| Jump to the edge of the data | Ctrl+Arrow |
| Extend the selection | Shift+Arrow, Shift+click |
| Select column, row, all | Ctrl+Space, Shift+Space, Ctrl+A |
| Quick formula | Alt+= |
| Bold, italic, underline | Ctrl+B, Ctrl+I, Ctrl+U |
| Fill down, fill right | Ctrl+D, Ctrl+R |
| Copy, cut, paste | Ctrl+C, Ctrl+X, Ctrl+V |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Clear contents | Delete |
| Next or previous tab | Ctrl+Page Down, Ctrl+Page Up |
| Rename the table | Shift+F2 |
| Save now (autosave already handles it) | Ctrl+S |
